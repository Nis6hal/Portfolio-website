Technical Implementation: Debounced Search Hook

Preventing search flood was accomplished with a custom React debounce hook that isolates state updates until user typing pauses:

useDebounce.ts
import { useState, useEffect } from 'react';

export function useDebounce<T>(value: T, delay: number = 350): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    const handler = setTimeout(() => setDebouncedValue(value), delay);
    return () => clearTimeout(handler);
  }, [value, delay]);

  return debouncedValue;
}

Engineering Challenges & Solutions

Challenge 1: API Rate Limiting on Rapid Search Typing

Typing in search bars without safeguards triggers dozens of redundant HTTP requests, triggering TMDb rate limits. Implemented a custom useDebounce React hook that waits 350ms post-keystroke, reducing outbound API calls by over 75%.

Challenge 2: Image Heavy Grid Performance

Loading hundreds of high-res backdrop and poster images can bog down browser memory. Implemented native lazy loading with blur placeholders and prioritized loading only for above-the-fold viewport elements.
