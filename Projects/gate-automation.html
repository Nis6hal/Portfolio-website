The Problem & Context

Manual gate security relies heavily on physical passes, paper entry logs, and human vigilance, leading to security bottlenecks during peak hours, human clerical errors, and unauthorized access vulnerabilities.

This project automated the complete access loop: from camera vehicle detection to real-time optical plate parsing, whitelist database matching, and servo barrier activation—all running on affordable, localized compute hardware.

Key Capabilities

Real-Time 30 FPS Stream

Continuous video pipeline that extracts vehicle frames, detects bounding regions of interest, and isolates plate contours on the fly.

Multi-Format OCR

Trained neural network models to recognize both standard international Latin characters and embossed regional plate formats.

Microcontroller Barrier Relay

Serial communication with ESP32 actuators to trigger physical barrier gates upon verified cryptographic whitelist matching.

Audit Logging & Timestamps

Structured SQLite storage capturing timestamped vehicle logs, entry/exit durations, and captured plate image snapshots.

Hardware-Software Pipeline

Frame Acquisition

Video frames are ingested, resized, and passed through grayscale, bilateral filter smoothing, and adaptive edge thresholding.

Plate Localization

Contour approximation filters rectangular license plate regions, validating aspect ratios before feeding into the OCR model.

Verification & Trigger

The parsed string is sanitized, verified against the database whitelist, and a serial signal triggers the ESP32 servo barrier.

Engineering Challenges & Solutions

Challenge 1: Variable Outdoor Lighting & Glare

Direct sunlight, shadows, and night-time headlight glare distorted character recognition. An adaptive thresholding pipeline using CLAHE (Contrast Limited Adaptive Histogram Equalization) was implemented, normalizing image contrast before segmentation.

Challenge 2: Low-Latency Inference on Constrained Hardware

Heavy deep learning models caused frame drops on mini-PCs. We optimized the model architecture to a lightweight quantized CNN (MobileNet backbone), shrinking inference time to under 80ms while maintaining 98%+ detection precision.

ESP32 Firmware & Actuator Control

The physical gate is driven by an ESP32 microcontroller that receives serial commands from the Python vision server and controls the barrier servo. The firmware is designed for reliability and safe failure modes.

Serial Protocol

A simple text-based protocol over UART carries commands such as OPEN, CLOSE, and STATUS, making the link easy to debug and extend.

Fail-Safe Behavior

If the serial link drops or the vision server crashes, the gate defaults to a locked state. A hardware watchdog timer resets the ESP32 if it hangs, ensuring access is never left unguarded.

Blynk IoT Dashboard

The ESP32 syncs state with the Blynk mobile app, allowing remote gate status monitoring and manual override from a smartphone when needed.

Whitelist & Audit Logging Schema

The SQLite database on the vision server maintains two key tables: the whitelist of authorized plates and the transaction audit log. Every access attempt — granted or denied — is recorded with a timestamp and the raw plate text.

Whitelist Table

Stores normalized plate strings, vehicle owner info, and access group membership. Entries can be added, edited, or revoked through a simple admin interface or direct SQL.

Audit Log Table

Records every detection event with plate text, match result, gate action, and a timestamp. This log powers usage reports and can be exported for security reviews.

Usage Analytics

Aggregated logs reveal peak entry/exit hours, average daily vehicle count, and unrecognized plate frequency — useful for parking capacity planning.

Lessons Learned & Outcomes

This project highlighted how much computer vision systems depend on their preprocessing pipeline. The CLAHE normalization step turned out to be the single most impactful change — without it, accuracy dropped sharply in challenging lighting. Hardware safety also proved just as important as model accuracy; a vision system that fails closed is far safer than one that fails open.

The final system achieved 98%+ plate recognition accuracy with sub-100ms inference on affordable mini-PC hardware, making automated gate access viable for small-scale deployments without expensive enterprise infrastructure.
